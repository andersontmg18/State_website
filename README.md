# State Website

A responsive informational website built to present U.S. state-related content in a clean and organized layout. This project was created to practice frontend development fundamentals, website structure, responsive design, and GitHub Pages deployment.

## Live Demo

[View Website](https://andersontmg18.github.io/State_website/)

## Project Purpose

This project serves as a deployed frontend portfolio piece while I continue building larger full-stack applications such as Remembly. It demonstrates my ability to create, organize, and publish a static website using HTML, CSS, and JavaScript.

## Features

- Responsive webpage layout
- Organized state information
- Clean navigation structure
- User-friendly design
- Deployed with GitHub Pages
- Beginner-friendly frontend architecture

## Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## What I Learned

Through this project, I practiced:

- Structuring a static website
- Styling pages with CSS
- Creating a responsive layout
- Organizing files for a web project
- Publishing a project using GitHub Pages
- Maintaining a public GitHub repository
